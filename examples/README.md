# Examples

This directory contains KDG files.

| File | Contents |
|------|----------|
| `contacts.kdg` | Contacts |
| `analytics.kdg` | Analytics |
| `inventory.kdg` | Inventory |
| `tasks.kdg` | Tasks |
| `config.kdg` | Configuration |

## Usage

```bash
python ../implementations/kdg.py parse contacts.kdg
```

## Notes

The delimiter `@` is not used for email fields because email addresses contain `@`. This is the kind of thing you learn.
